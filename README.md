A simple HTML page that can be used as an 'anchor' of sorts for a window, with a ***chonky big*** title and a markdown-formatted bit of content, for showing links and such. 

Built for my own workflow: a browser window per project, and a tab suspender to free up RAM for tabs that haven't been accessed for while. I needed something that I could 
fairly easily add important links, such as links to documents and our CRM, while being mega lightweight so it would not use too many resources. 

The H1 tag is ***chonky big*** so that it can be read easily in Windows' ALT+TAB interface. 

Comes bundled with a copy of `purify.js` and `marked.js`, so this repo is ready to download or clone and immediately use - no dependency faff, no build faff, no node faff.
